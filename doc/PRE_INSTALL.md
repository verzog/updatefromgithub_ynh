This app can trigger upgrades of your other YunoHost apps, so its dashboard is
restricted to the **admins** group and must stay that way. Do not open the
permission to `visitors` or `all_users`.

During install you can optionally provide a GitHub personal access token. It is
only needed for **private** repositories or to raise GitHub's anonymous API
rate limit; leave it empty for public repositories. You can set or change it
later from the dashboard's Settings panel.
